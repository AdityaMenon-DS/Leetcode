##  Problem-Solving Approach
**I will be solving 3 problems everyday from 1st September 2026 without break**
For each problem, I try to:

1. Understand the problem clearly
2. Think of a simple/brute-force solution
3. Identify possible optimizations
4. Write clean and readable code
5. Analyze **time complexity**
6. Analyze **space complexity**
7. Learn the pattern behind the solution
